## Settings

<Collapse title="Show all settings" kind="settings">

**General**

| Setting | Default | Purpose |
|---------|---------|---------|
| **Enabled** | off | Master on/off switch for the assistant |
| **Api key** | - | Key used to authenticate against the AI API |
| **Url Api Service** | `https://cv4pve-admin.corsinvest.it/api` | Endpoint of the AI service backing the assistant |

**CSV**

| Setting | Default | Purpose |
|---------|---------|---------|
| **Separator** | `;` | Column separator used when exporting tabular replies as CSV |

**HTML**

| Setting | Default | Purpose |
|---------|---------|---------|
| **Decorate value with emoji** | on | Add emoji indicators based on warning/critical thresholds |
| **Warning** | 80 | Value at or above which the warning indicator is used |
| **Critical** | 90 | Value at or above which the critical indicator is used |

**Markdown**

| Setting | Default | Purpose |
|---------|---------|---------|
| **Decorate value with emoji** | on | Add emoji indicators based on warning/critical thresholds |
| **Warning** | 80 | Value at or above which the warning indicator is used |
| **Critical** | 90 | Value at or above which the critical indicator is used |

</Collapse>
