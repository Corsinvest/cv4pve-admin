## Modules and Features

What each edition gives you, module by module. The [Modules](../modules/) page groups them by category.

| Module | Community | Enterprise |
|--------|-----------|------------|
| **[Admin Area](../configuration/admin-area/)** | Cluster management and administration (CE: Single user `admin@local`, no user management) | Everything in Community except the **Support** page, plus: <ul><li>User management with roles and permissions</li><li>App Tokens</li><li>Audit Logs</li><li>Appearance settings</li><li>Log Cleanup</li><li>System Logs</li></ul> |
| **AI Assistant** | In design: built-in chat assistant integrated directly into cv4pve-admin. Not included in the current builds | Same as Community |
| **[AI Server (MCP)](../modules/ai-server/)** | Model Context Protocol server for AI integration with 29 tools for clusters, VMs, nodes, storage, backups, ISO/template management, replications and historical metrics | Everything in Community, plus: <ul><li>2 additional SQL-like query tools (`GetQuerySchema`, `ExecuteQuery`) on cluster data with filters, grouping, aggregates</li></ul> |
| **[AutoSnap](../modules/autosnap/)** | Automated snapshot scheduling with retention policies | Everything in Community, plus: <ul><li>Web API Hook: trigger HTTP webhooks on snapshot phase events (before/after create, before/after delete)</li><li>Daily Status widget (successful/failed snapshots per day, last 14 days)</li></ul> |
| **[Backup Analytics](../modules/backup-analytics/)** | Backup job analysis and monitoring | Everything in Community, plus: <ul><li>Daily Status widget (successful/failed backups per day, last 14 days)</li></ul> |
| **[Bots](../modules/bots/)** | Remote cluster management via Telegram | Same as Community |
| **[Command Palette](../modules/command-palette/)** | Quick access to commands and navigation (`Ctrl+K`) | Everything in Community, plus: <ul><li>The Enterprise modules among the results (UPS Monitor, VM Performance, Workflow, Portal)</li></ul> |
| **[Dashboard](../modules/dashboard/)** | Customizable dashboards with widgets and metrics | Everything in Community, plus: <ul><li>The widgets added by the Enterprise editions of the modules</li></ul> |
| **Disaster Recovery (DDR)** | Not available | In design: disaster recovery with Ceph RBD Mirror. Not included in the current builds |
| **[Diagnostics](../modules/diagnostics/)** | Infrastructure diagnostics, health checks and report export (PDF + Excel) | Everything in Community, plus: <ul><li>Executive Summary on PDF (counts per gravity + top critical issues)</li><li>Compliance mapping to 18 standards (ISO 27001, NIS2, DORA, …) in PDF / Excel reports and in the scan detail</li></ul> |
| **[Metrics Exporter](../modules/metrics-exporter/)** | Exposes Proxmox VE metrics for monitoring systems (Prometheus) | Same as Community |
| **[Node Protect](../modules/node-protect/)** | Node configuration backup | Everything in Community, plus: <ul><li>Git provider integration with automatic push</li><li>Daily Status widget (last 14 days) and Git repository size widget</li></ul> |
| **[Notifier](../configuration/admin-area/notifier/)** | Notification system (CE: SMTP + WebHook only) | Everything in Community, plus: <ul><li>140+ services (Telegram, Discord, Slack, Teams, and more...)</li></ul> |
| **[Portal](../modules/portal/)** | Not available | Multi-tenant portal: tenants bound to a cluster, with their VMs/CTs and users with per-VM permissions |
| **[Profile](../configuration/profile/)** | User profile management | Everything in Community, plus: <ul><li>Two-factor authentication (2FA)</li><li>Audit Logs</li></ul> |
| **[Replication Analytics](../modules/replication-analytics/)** | Replication job monitoring and analysis | Everything in Community, plus: <ul><li>Daily Status widget (successful/failed replications per day, last 14 days)</li></ul> |
| **[Resources](../modules/resources/)** | Real-time cluster and resource monitoring | Everything in Community, plus: <ul><li>Snapshot size calculation and snapshot usage view</li></ul> |
| **[System Report](../modules/system-report/)** | Comprehensive cluster/VM/node/storage reports | Everything in Community, plus: <ul><li>Daily Status widget (successful/failed reports per day, last 14 days)</li></ul> |
| **[Update Manager](../modules/update-manager/)** | System update management with parallel scan and report export (PDF + Excel) | Same as Community |
| **[UPS Monitor](../modules/ups-monitor/)** | Not available | Network UPS monitoring via SNMP |
| **[VM Performance](../modules/vm-performance/)** | Not available | VM performance tracking with per-disk IOPS and throughput |
| **[Workflow](../modules/workflow/)** | Not available | Visual workflow designer with 24 Proxmox VE activities (guests, snapshots, nodes, storage, HA, replication) plus notification and filter activities |
