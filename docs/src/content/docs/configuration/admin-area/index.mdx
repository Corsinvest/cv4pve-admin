System administration, security, monitoring and Proxmox VE cluster configuration, all under one menu.

## Access

Open the **Admin Area** from the profile menu: click your avatar in the top right corner of the application. The Admin Area is not listed in the main menu on the left.

The Admin Area applies to the whole application, not to the cluster selected in the top bar.

## Overview

The first page of the Admin Area. It is a short introduction to what the area contains (infrastructure, access control, operations) and has no settings.

## Support

<Tag kind="ce" /> Shown in the Community Edition only. The page describes the two support options:

- **Community Support**: link to the cv4pve-admin project on GitHub, where questions and discussions are welcome. A response is not guaranteed.
- **Dedicated Support**: enterprise support included with the subscriptions, with a **See Pricing** button that opens the Corsinvest shop.

In both editions the help menu (the **?** icon in the top bar) also has a **Support** entry that opens the GitHub issues of the project.
